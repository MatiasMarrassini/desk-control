# Desk Control — etapa 2 (pestaña "Cuarto", focos WiZ): plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Sumar al widget una pestaña que controla los dos focos WiZ del cuarto, sincronizados por defecto, con control individual opcional, escenas y estado por foco, sin quitarle el control a la app del celular.

**Architecture:** Tres módulos nuevos en `widget/dispositivos/`:
- `wiz_protocolo.py`: mensajes y lista blanca.
- `wiz_transporte.py`: UDP con asyncio sin sockets en escucha en puertos fijos.
- `wiz.py`: `GrupoWiz`, con estado, envío en paralelo, consulta periódica y re-ubicación por MAC.

Corren en el mismo bucle asyncio que el Bluetooth. El `Puente` se generaliza a dos tipos de dispositivo (`xeno` y `wiz_grupo`). La interfaz suma `luces.js`/`luces.css` (`VistaLuces`) con la misma interfaz de vista que `VistaSable`.

**Tech Stack:** Python 3.12 (`asyncio` UDP, sin dependencias nuevas) · pytest + pytest-asyncio · HTML/CSS/JS sin frameworks.

**Spec:** `docs/superpowers/specs/2026-10-13-luces-wiz-design.md` (etapa 1: `docs/superpowers/specs/2026-10-12-widget-sable-design.md`).

## Global Constraints

- Sin dependencias nuevas. Los comandos se ejecutan desde la raíz con `.venv/Scripts/python`.
- **Sin sockets en escucha en un puerto fijo:** los pedidos UDP usan sockets efímeros que solo reciben su respuesta. No se usa `registration`/`syncPilot` (push de los focos).
- **Lista blanca WiZ:**
  - Métodos permitidos: `getPilot`, `getSystemConfig` y `setPilot`.
  - Parámetros de `setPilot`: `state` (bool), `dimming` (10–100), `r`/`g`/`b` (0–255, los tres juntos), `temp` (2200–6500), `sceneId` (tabla de escenas), `speed` (10–200, solo con escena animada).
  - Color, temperatura y escena no se combinan entre sí.
- Puerto WiZ 38899. Por foco: timeout de respuesta 0,6 s y 3 intentos. Re-búsqueda por MAC como máximo cada 30 s. Consulta periódica cada 5 s, solo con la ventana visible y la pestaña del grupo activa.
- Identidad de cada foco = MAC (en minúsculas, como la reporta el foco). La IP se guarda y se actualiza.
- Tipo de dispositivo del grupo: `wiz_grupo`, con `direccion` = `"WIZ:<roomId>"`. Nombre por defecto `"Cuarto"`; focos `"Foco 1"`, `"Foco 2"`…
- Favoritas: 7 como máximo; por defecto `[12, 15, 16, 14, 4, 5, 1]` (Luz de día, Concentración, Relax, Luz nocturna, Fiesta, Chimenea, Océano).
- Texto que viene de los focos o del usuario: solo `textContent`.
- Mismas reglas de interfaz que la etapa 1: 380×600, tema oscuro, español rioplatense. Deslizadores: como máximo un envío cada 150 ms y el valor final al soltar.
- Commits en español, terminados con `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`, seguidos de `git push`.

```python
"""Protocolo local de los focos WiZ: JSON por UDP al puerto 38899 (ver NOTAS.md y la spec de la etapa 2).

Lista blanca: solo se leen estados (getPilot, getSystemConfig) y se envían órdenes de luz (setPilot).
"""
import json

PUERTO = 38899
_LECTURAS = frozenset({"getPilot", "getSystemConfig"})

# Nombres oficiales de la app WiZ en español; IDs según la documentación de la comunidad (pywizlight).
ESCENAS_FIJAS = {
    6: "Acogedor", 11: "Blanco cálido", 12: "Luz de día", 13: "Blanco frío", 14: "Luz nocturna",
    15: "Concentración", 16: "Relax", 17: "Colores reales", 18: "Hora de la tele", 19: "Crecimiento de planta",
}
ESCENAS_ANIMADAS = {
    1: "Océano", 2: "Romance", 3: "Atardecer", 4: "Fiesta", 5: "Chimenea", 7: "Bosque", 8: "Colores pastel",
    9: "Despertar", 10: "Hora de acostarse", 20: "Primavera", 21: "Verano", 22: "Otoño", 23: "Inmersión profunda",
    24: "Jungla", 25: "Mojito", 26: "Club", 27: "Navidad", 28: "Halloween", 29: "Luz de vela", 30: "Blanco dorado",
    31: "Pulso", 32: "Steampunk", 33: "Diwali",
}
ESCENAS = {**ESCENAS_FIJAS, **ESCENAS_ANIMADAS}
FAVORITAS_POR_DEFECTO = [12, 15, 16, 14, 4, 5, 1]
MAX_FAVORITAS = 7

_PARAMS = frozenset({"state", "dimming", "r", "g", "b", "temp", "sceneId", "speed"})
_RGB = ("r", "g", "b")


class ComandoInvalido(ValueError):
    """El método o los parámetros no están permitidos."""


def _entero(valor, minimo: int, maximo: int) -> bool:
    return isinstance(valor, int) and not isinstance(valor, bool) and minimo <= valor <= maximo


def validar_params(params: dict) -> None:
    if not isinstance(params, dict) or not params:
        raise ComandoInvalido("Parámetros vacíos o inválidos")
    extra = set(params) - _PARAMS
    if extra:
        raise ComandoInvalido(f"Parámetro no permitido: {sorted(extra)[0]}")
    if "state" in params and not isinstance(params["state"], bool):
        raise ComandoInvalido("state debe ser true o false")
    if "dimming" in params and not _entero(params["dimming"], 10, 100):
        raise ComandoInvalido("El brillo va de 10 a 100")
    if "temp" in params and not _entero(params["temp"], 2200, 6500):
        raise ComandoInvalido("La temperatura va de 2200 a 6500 K")
    if "sceneId" in params and params["sceneId"] not in ESCENAS:
        raise ComandoInvalido("Escena desconocida")
    hay_rgb = [k in params for k in _RGB]
    if any(hay_rgb) and not all(hay_rgb):
        raise ComandoInvalido("El color necesita r, g y b")
    if all(hay_rgb) and not all(_entero(params[k], 0, 255) for k in _RGB):
        raise ComandoInvalido("Cada componente de color va de 0 a 255")
    if sum([all(hay_rgb), "temp" in params, "sceneId" in params]) > 1:
        raise ComandoInvalido("Color, temperatura y escena no se combinan")
    if "speed" in params and (params.get("sceneId") not in ESCENAS_ANIMADAS or not _entero(params["speed"], 10, 200)):
        raise ComandoInvalido("La velocidad (10–200) solo vale con una escena animada")


def armar_set(params: dict) -> bytes:
    validar_params(params)
    return json.dumps({"method": "setPilot", "params": params}, separators=(",", ":")).encode("utf-8")


def armar_lectura(metodo: str) -> bytes:
    if metodo not in _LECTURAS:
        raise ComandoInvalido(f"Método no permitido: {metodo}")
    return json.dumps({"method": metodo, "params": {}}, separators=(",", ":")).encode("utf-8")


def interpretar(datos: bytes) -> dict | None:
    """Respuesta JSON de un foco ({"method": ..., ...}) o None si no es válida."""
    try:
        mensaje = json.loads(datos.decode("utf-8"))
    except (UnicodeDecodeError, ValueError):
        return None
    if isinstance(mensaje, dict) and isinstance(mensaje.get("method"), str):
        return mensaje
    return None


def lista_escenas() -> list[dict]:
    fijas = [{"id": i, "nombre": n, "animada": False} for i, n in ESCENAS_FIJAS.items()]
    animadas = [{"id": i, "nombre": n, "animada": True} for i, n in ESCENAS_ANIMADAS.items()]
    return fijas + animadas
```

```python
"""Foco WiZ falso: responde por UDP en 127.0.0.1 (puerto efímero) como los focos reales."""
import asyncio
import json


class FocoSimulado(asyncio.DatagramProtocol):
    def __init__(self, mac="444f8e000001", room_id=23013550, perder=0, metodo_equivocado=False):
        self.mac = mac
        self.room_id = room_id
        self.estado = {"state": True, "sceneId": 12, "temp": 4200, "dimming": 100}
        self.recibidos: list[dict] = []
        self.activo = True             # False = foco sin corriente (no responde)
        self.perder = perder           # cantidad de pedidos a ignorar (pérdida de paquetes)
        self.metodo_equivocado = metodo_equivocado  # responde primero con otro método
        self.puerto = None
        self._transporte = None

    def connection_made(self, transporte):
        self._transporte = transporte

    def datagram_received(self, datos, origen):
        if not self.activo:
            return
        mensaje = json.loads(datos)
        self.recibidos.append(mensaje)
        if self.perder > 0:
            self.perder -= 1
            return
        if self.metodo_equivocado:
            self.metodo_equivocado = False
            self._responder(origen, "getSystemConfig", {"mac": self.mac})
        metodo = mensaje.get("method")
        if metodo == "getPilot":
            self._responder(origen, metodo, {"mac": self.mac, "rssi": -73, **self.estado})
        elif metodo == "getSystemConfig":
            self._responder(origen, metodo, {"mac": self.mac, "homeId": 1, "roomId": self.room_id, "groupId": 3,
                                             "moduleName": "ESP24_SHRGBC_01", "fwVersion": "1.38.0"})
        elif metodo == "setPilot":
            self._aplicar(mensaje["params"])
            self._responder(origen, metodo, {"success": True})
        else:
            datos = {"method": metodo, "error": {"code": -32601, "message": "Method not found"}}
            self._transporte.sendto(json.dumps(datos).encode(), origen)

    def _aplicar(self, params):
        if "temp" in params:
            for k in ("r", "g", "b"):
                self.estado.pop(k, None)
            self.estado["sceneId"] = 0
        if "r" in params:
            self.estado.pop("temp", None)
            self.estado["sceneId"] = 0
        if "sceneId" in params:
            for k in ("r", "g", "b", "temp"):
                self.estado.pop(k, None)
        self.estado.update({k: v for k, v in params.items() if k != "speed"})

    def _responder(self, origen, metodo, resultado):
        respuesta = {"method": metodo, "env": "pro", "result": resultado}
        self._transporte.sendto(json.dumps(respuesta).encode(), origen)

    def cerrar(self):
        if self._transporte:
            self._transporte.close()


async def iniciar_foco(**opciones) -> FocoSimulado:
    foco = FocoSimulado(**opciones)
    transporte, _ = await asyncio.get_running_loop().create_datagram_endpoint(
        lambda: foco, local_addr=("127.0.0.1", 0))
    foco.puerto = transporte.get_extra_info("sockname")[1]
    return foco
```

```python
"""UDP con asyncio para los focos WiZ.

No hay sockets en escucha en un puerto fijo: cada pedido o búsqueda usa un socket efímero que solo recibe
las respuestas a lo que envió, y se cierra al terminar.
"""
import asyncio
import ipaddress
import socket

from widget.dispositivos.wiz_protocolo import PUERTO, interpretar


class _Receptor(asyncio.DatagramProtocol):
    def __init__(self):
        self.cola: asyncio.Queue = asyncio.Queue()

    def datagram_received(self, datos, origen):
        self.cola.put_nowait((datos, origen))

    def error_received(self, exc):
        pass  # p. ej. "puerto inalcanzable": se trata como falta de respuesta


def ip_local() -> str:
    """IP de esta PC en la red local ("conectar" un socket UDP no envía nada: solo elige la interfaz)."""
    with socket.socket(socket.AF_INET, socket.SOCK_DGRAM) as s:
        s.connect(("10.255.255.255", 1))
        return s.getsockname()[0]


def direccion_difusion(ip: str) -> str:
    return str(ipaddress.ip_network(f"{ip}/24", strict=False).broadcast_address)


async def _esperar(receptor: _Receptor, segundos: float):
    try:
        return await asyncio.wait_for(receptor.cola.get(), segundos)
    except asyncio.TimeoutError:
        return None


async def pedir(ip: str, mensaje: bytes, *, metodo: str, puerto: int = PUERTO, timeout: float = 0.6,
                intentos: int = 3) -> dict | None:
    """Envía `mensaje` y devuelve la primera respuesta válida del mismo `metodo`, reintentando si se pierde."""
    loop = asyncio.get_running_loop()
    transporte, receptor = await loop.create_datagram_endpoint(_Receptor, remote_addr=(ip, puerto))
    try:
        for _ in range(intentos):
            transporte.sendto(mensaje)
            fin = loop.time() + timeout
            while (resto := fin - loop.time()) > 0:
                llegada = await _esperar(receptor, resto)
                if llegada is None:
                    break
                respuesta = interpretar(llegada[0])
                if respuesta is not None and respuesta.get("method") == metodo:
                    return respuesta
        return None
    finally:
        transporte.close()


async def difundir(mensajes: list[bytes], destinos: list[tuple[str, int]], *,
                   segundos: float = 2.0) -> list[tuple[tuple[str, int], dict]]:
    """Envía cada mensaje a cada destino (p. ej. la dirección de difusión) y junta respuestas por `segundos`."""
    loop = asyncio.get_running_loop()
    transporte, receptor = await loop.create_datagram_endpoint(
        _Receptor, local_addr=("0.0.0.0", 0), allow_broadcast=True)
    try:
        for destino in destinos:
            for mensaje in mensajes:
                transporte.sendto(mensaje, destino)
        respuestas = []
        fin = loop.time() + segundos
        while (resto := fin - loop.time()) > 0:
            llegada = await _esperar(receptor, resto)
            if llegada is None:
                break
            respuesta = interpretar(llegada[0])
            if respuesta is not None:
                respuestas.append((tuple(llegada[1][:2]), respuesta))
        return respuestas
    finally:
        transporte.close()
```

```python
"""Grupo de focos WiZ: órdenes sincronizadas, estado por foco, consulta periódica y re-ubicación por MAC."""
import asyncio
import contextlib
import logging
import math
import time
from typing import Awaitable, Callable

from widget.dispositivos import wiz_protocolo as p
from widget.dispositivos import wiz_transporte as t

log = logging.getLogger(__name__)

ESPERA = "espera"
CONECTADO = "conectado"
PARCIAL = "parcial"
SIN_RESPUESTA = "sin_respuesta"
BUSCANDO = "buscando"

_MODOS = (frozenset({"r", "g", "b"}), frozenset({"temp"}), frozenset({"sceneId"}))
CLAVES_ESTADO = ("state", "dimming", "temp", "r", "g", "b", "sceneId")


def combinar(estado: dict, params: dict) -> dict:
    """Aplica `params` sobre `estado`: color, temperatura y escena se excluyen entre sí."""
    nuevo = dict(estado)
    for modo in _MODOS:
        if modo & params.keys():
            for otro in _MODOS:
                if otro is not modo:
                    for clave in otro:
                        nuevo.pop(clave, None)
    nuevo.update({k: v for k, v in params.items() if k != "speed"})
    return nuevo


def params_de_pilot(resultado: dict) -> dict:
    """Estado normalizado de un getPilot: estado, brillo y UNO de escena / color / temperatura."""
    salida = {}
    if "state" in resultado:
        salida["state"] = bool(resultado["state"])
    if "dimming" in resultado:
        salida["dimming"] = resultado["dimming"]
    if resultado.get("sceneId"):
        salida["sceneId"] = resultado["sceneId"]
    elif all(k in resultado for k in ("r", "g", "b")):
        salida.update(r=resultado["r"], g=resultado["g"], b=resultado["b"])
    elif "temp" in resultado:
        salida["temp"] = resultado["temp"]
    return salida


class GrupoWiz:
    def __init__(self, focos: list[dict], *, estado_inicial: dict | None = None,
                 buscar: Callable[[], Awaitable[list]] | None = None, intervalo: float = 5.0,
                 timeout: float = 0.6, intentos: int = 3, espera_rebusqueda: float = 30.0):
        self.focos = [{"mac": f["mac"], "nombre": f.get("nombre", ""), "ip": f["ip"],
                       "puerto": f.get("puerto", p.PUERTO), "estado": {}, "responde": None} for f in focos]
        self.estado = {k: v for k, v in (estado_inicial or {}).items() if k in CLAVES_ESTADO}
        self.conexion = ESPERA
        self.al_evento: Callable[[str, dict], None] | None = None
        self._buscar = buscar or self._buscar_en_red
        self._intervalo = intervalo
        self._timeout = timeout
        self._intentos = intentos
        self._espera_rebusqueda = espera_rebusqueda
        self._ultima_busqueda = -math.inf
        self._ubicaciones: dict[str, tuple[str, int]] = {}
        self._candado_busqueda = asyncio.Lock()
        self._tarea_consulta: asyncio.Task | None = None
        self._ultima_conexion = None

    @property
    def sincronizados(self) -> bool:
        estados = [f["estado"] for f in self.focos if f["responde"]]
        return all(e == estados[0] for e in estados[1:])

    # ---- órdenes ----
    async def enviar(self, params: dict, mac: str | None = None) -> bool:
        """Envía setPilot al grupo (o a un foco). True si al menos un foco confirmó."""
        mensaje = p.armar_set(params)  # valida: lanza ComandoInvalido
        destinos = [f for f in self.focos if mac is None or f["mac"] == mac]
        if not destinos:
            raise KeyError("Foco desconocido")
        resultados = await asyncio.gather(*(self._enviar_a(f, mensaje, params) for f in destinos))
        if mac is None and any(resultados):
            self.estado = combinar(self.estado, params)
        self._actualizar_conexion()
        self._emitir_estado()
        return any(resultados)

    async def sincronizar(self) -> bool:
        params = {k: v for k, v in self.estado.items() if k in CLAVES_ESTADO}
        if not params:
            return False
        return await self.enviar(params)

    async def _enviar_a(self, foco: dict, mensaje: bytes, params: dict) -> bool:
        respuesta = await self._pedir(foco, mensaje, "setPilot")
        ok = bool(respuesta) and isinstance(respuesta.get("result"), dict) and respuesta["result"].get("success") is True
        if ok:
            foco["estado"] = combinar(foco["estado"], params)
        return ok

    # ---- lectura ----
    async def consultar(self) -> None:
        mensaje = p.armar_lectura("getPilot")
        respuestas = await asyncio.gather(*(self._pedir(f, mensaje, "getPilot") for f in self.focos))
        for foco, respuesta in zip(self.focos, respuestas):
            if respuesta and isinstance(respuesta.get("result"), dict):
                foco["estado"] = params_de_pilot(respuesta["result"])
        primero = next((f for f in self.focos if f["responde"]), None)
        if primero is not None:
            self.estado = dict(primero["estado"])
        self._actualizar_conexion()
        self._emitir_estado()

    async def visible(self, si: bool) -> None:
        """Con la pestaña visible consulta cada `intervalo` s; oculta, no consulta nada."""
        if si and (self._tarea_consulta is None or self._tarea_consulta.done()):
            self._tarea_consulta = asyncio.create_task(self._consultar_siempre())
        elif not si and self._tarea_consulta is not None:
            self._tarea_consulta.cancel()
            with contextlib.suppress(asyncio.CancelledError):
                await self._tarea_consulta
            self._tarea_consulta = None

    async def reintentar(self) -> None:
        self._ultima_busqueda = -math.inf
        await self.consultar()

    async def cerrar(self) -> None:
        await self.visible(False)

    def renombrar_foco(self, mac: str, nombre: str) -> None:
        for foco in self.focos:
            if foco["mac"] == mac:
                foco["nombre"] = nombre

    def vista_focos(self) -> list[dict]:
        return [{"mac": f["mac"], "nombre": f["nombre"], "estado": dict(f["estado"]), "responde": f["responde"]}
                for f in self.focos]

    # ---- interno ----
    async def _consultar_siempre(self) -> None:
        while True:
            try:
                await self.consultar()
            except Exception:
                log.exception("Error al consultar los focos")
            await asyncio.sleep(self._intervalo)

    async def _pedir(self, foco: dict, mensaje: bytes, metodo: str) -> dict | None:
        respuesta = await self._pedir_ip(foco, mensaje, metodo)
        if respuesta is None and await self._reubicar(foco):
            respuesta = await self._pedir_ip(foco, mensaje, metodo)
        foco["responde"] = respuesta is not None
        return respuesta

    async def _pedir_ip(self, foco: dict, mensaje: bytes, metodo: str) -> dict | None:
        try:
            return await t.pedir(foco["ip"], mensaje, metodo=metodo, puerto=foco["puerto"],
                                 timeout=self._timeout, intentos=self._intentos)
        except OSError:
            return None

    async def _reubicar(self, foco: dict) -> bool:
        """Busca por MAC la dirección nueva del foco (difusión), como máximo cada `espera_rebusqueda` s."""
        async with self._candado_busqueda:
            if time.monotonic() - self._ultima_busqueda >= self._espera_rebusqueda:
                self._ultima_busqueda = time.monotonic()
                self._cambiar_conexion(BUSCANDO)
                try:
                    encontrados = await self._buscar()
                except OSError:
                    encontrados = []
                self._ubicaciones = {
                    r["result"]["mac"]: origen for origen, r in encontrados
                    if isinstance(r.get("result"), dict) and r["result"].get("mac")}
            nueva = self._ubicaciones.get(foco["mac"])
            if nueva is None or (nueva[0], nueva[1]) == (foco["ip"], foco["puerto"]):
                return False
            foco["ip"], foco["puerto"] = nueva[0], nueva[1]
            self._emitir("ip", {"mac": foco["mac"], "ip": foco["ip"]})
            return True

    async def _buscar_en_red(self) -> list:
        destino = (t.direccion_difusion(t.ip_local()), p.PUERTO)
        return await t.difundir([p.armar_lectura("getSystemConfig")], [destino], segundos=2.0)

    def _actualizar_conexion(self) -> None:
        total = len(self.focos)
        responden = sum(1 for f in self.focos if f["responde"])
        estado = CONECTADO if responden == total else PARCIAL if responden else SIN_RESPUESTA
        self._cambiar_conexion(estado, responden=responden, total=total)

    def _cambiar_conexion(self, estado: str, **extra) -> None:
        clave = (estado, tuple(sorted(extra.items())))
        self.conexion = estado
        if clave != self._ultima_conexion:  # no repetir el mismo evento en cada consulta
            self._ultima_conexion = clave
            self._emitir("conexion", {"estado": estado, **extra})

    def _emitir_estado(self) -> None:
        self._emitir("estado", {"grupo": dict(self.estado), "focos": self.vista_focos(),
                                "sincronizados": self.sincronizados})

    def _emitir(self, tipo: str, datos: dict) -> None:
        if self.al_evento is None:
            return
        try:
            self.al_evento(tipo, datos)
        except Exception:
            log.exception("Error al emitir el evento %s", tipo)
```

```python
from widget.dispositivos import wiz_protocolo as wp
from widget.dispositivos import wiz_transporte as wt


async def buscar_focos(destinos: list[tuple[str, int]] | None = None, segundos: float = 2.0) -> list[dict]:
    """Focos WiZ de la red local (difusión de getSystemConfig y getPilot; solo lectura)."""
    if destinos is None:
        destinos = [(wt.direccion_difusion(wt.ip_local()), wp.PUERTO)]
    respuestas = await wt.difundir([wp.armar_lectura("getSystemConfig"), wp.armar_lectura("getPilot")],
                                   destinos, segundos=segundos)
    focos: dict[str, dict] = {}
    for (ip, puerto), r in respuestas:
        resultado = r.get("result")
        if not isinstance(resultado, dict) or not isinstance(resultado.get("mac"), str):
            continue
        foco = focos.setdefault(resultado["mac"], {"mac": resultado["mac"], "ip": ip, "puerto": puerto,
                                                   "modelo": None, "room": None, "rssi": None})
        if r.get("method") == "getSystemConfig":
            foco["modelo"] = resultado.get("moduleName")
            foco["room"] = resultado.get("roomId")
        elif r.get("method") == "getPilot":
            foco["rssi"] = resultado.get("rssi")
    return sorted(focos.values(), key=lambda f: f["mac"])


def agrupar_por_cuarto(focos: list[dict]) -> list[dict]:
    """Un grupo por habitación de la cuenta WiZ (roomId), con nombre sugerido "Cuarto"."""
    grupos: dict[str, dict] = {}
    for foco in focos:
        clave = str(foco.get("room") if foco.get("room") is not None else foco["mac"])
        grupo = grupos.setdefault(clave, {"tipo": "wiz_grupo", "clave": clave, "nombre": "Cuarto", "focos": []})
        grupo["focos"].append({"mac": foco["mac"], "ip": foco["ip"]})
    return list(grupos.values())
```

```js
  async enviar(params, mac = null) {
    const conEscena = "sceneId" in params ? { state: true, ...params } : params;
    if (mac) {
      const foco = this.focos.find((f) => f.mac === mac);

    input.focus();
    input.select();
    let terminado = false;
    const terminar = async (guardar) => {
      if (terminado) return;
      terminado = true;
      if (guardar && input.value.trim() && input.value.trim() !== foco.nombre) {
        const r = await pywebview.api.renombrar_foco(this.d.id, foco.mac, input.value);
        if (r.ok) foco.nombre = input.value.trim().replace(/\s+/g, " ");
        else util.aviso(r.error, "error");
      }
      this.pintar();
    };
    input.addEventListener("keydown", (e) => {
      if (e.key === "Enter") terminar(true);
      if (e.key === "Escape") { e.stopPropagation(); terminar(false); }
    });
    input.addEventListener("blur", () => terminar(true));
  }

        estrella.title = "Favorita";
        estrella.addEventListener("click", () => this.alternarFavorita(s.id));
        fila.append(elegir, estrella);

    }
    if (typeof pintarPestanas === "function") pintarPestanas();
  }
```

```python
"""Verifica con un foco real que cada sceneId de la tabla es aceptado y reportado igual (y restaura el estado).

Uso: python pruebas/wiz_escenas.py IP     (tarda ~1 minuto; el foco cambia de escena varias veces)
"""
import asyncio
import sys
from pathlib import Path

sys.path.insert(0, str(Path(__file__).resolve().parents[1]))

from widget.dispositivos import wiz_protocolo as w  # noqa: E402
from widget.dispositivos import wiz_transporte as t  # noqa: E402
from widget.dispositivos.wiz import params_de_pilot  # noqa: E402


async def main(ip: str) -> None:
    antes = await t.pedir(ip, w.armar_lectura("getPilot"), metodo="getPilot")
    if not antes:
        sys.exit("El foco no responde")
    original = params_de_pilot(antes["result"])
    malas = []
    for escena_id, nombre in w.ESCENAS.items():
        r = await t.pedir(ip, w.armar_set({"state": True, "sceneId": escena_id}), metodo="setPilot")
        await asyncio.sleep(1.2)
        leido = await t.pedir(ip, w.armar_lectura("getPilot"), metodo="getPilot")
        reportada = (leido or {}).get("result", {}).get("sceneId")
        ok = bool(r and r.get("result", {}).get("success")) and reportada == escena_id
        print(f"{escena_id:3d} {nombre:22s} {'OK' if ok else f'DISTINTA (reporta {reportada})'}")
        if not ok:
            malas.append(escena_id)
    await t.pedir(ip, w.armar_set(original), metodo="setPilot")
    print("Restaurado:", original)
    print("Todas verificadas" if not malas else f"Revisar: {malas}")


if __name__ == "__main__":
    asyncio.run(main(sys.argv[1]))
```
